What it does today

Help on the first page you visit, with no setup

No onboarding, no profile, no model, and no network. Each adjustment follows a published threshold instead of guessing.

  • Minimum text size

    Text smaller than 16px is raised to 16px. Text that is already bigger is left alone, so headings keep their hierarchy.

  • Readable spacing

    Line height 1.5, paragraph spacing 2×, letter spacing 0.12em, and word spacing 0.16em, applied only where the page uses less.

    WCAG 1.4.12 Text Spacing

  • Visible keyboard focus

    A thick amber outline shows where you are when you use the keyboard, even on sites that hide it.

    WCAG 2.4.7 Focus Visible

  • Calmer pages

    Stops animations, transitions, smooth scrolling, and autoplaying video or audio.

    WCAG 2.2.2 Pause, Stop, Hide

  • High contrast or dark

    Choose black on white or light on dark. People need opposite things here, so you choose instead of the site.

    WCAG 1.4.3 Contrast

  • Keeps up with the page

    Content that React, Vue, or any other framework adds later is adjusted too, as soon as it appears.

How it works

Your page stays on your computer

  1. Click the toolbar icon

    WebAble reads a tab only after you click its icon. It does not ask for permission to read every site you visit.

  2. It reads the page on your device

    It counts text size, headings, links, and controls. It never reads what you type into forms, and nothing is sent anywhere.

  3. Adjust, then undo anytime

    Changes are style rules layered on top of the site. Reset removes them all in one click.

Not an overlay

Accessibility overlays work for the site. WebAble works for you.

Overlay widgets are installed by site owners and claim to make a site compliant. Disability advocates reject them, and in 2025 the FTC fined a leading vendor $1 million over that claim. WebAble is the opposite on every point.

Accessibility overlays compared with WebAble

Honest limits

What we promise, and what we won't

A tool on your side of the screen can't fix everything. We say so up front.

We promise

  • Published thresholds for text size, spacing, and contrast
  • Safe alongside browser zoom and screen readers
  • Every change can be undone
  • Your page content never leaves your browser

We won't claim to fix

  • That any site becomes "compliant"
  • Missing alt text, captions, or audio description
  • Keyboard traps inside custom widgets
  • Session timeouts, server errors, or CAPTCHAs

Roadmap

From instant fixes to real understanding

Each stage adds help while keeping the rule that every change is checked and can be undone.

  1. Available now

    Tier 0: Instant

    Text, spacing, focus, motion, and contrast with no setup and no network.

  2. Next

    Tier 1: Calibrated

    A short calibration builds a preference profile that follows you from site to site.

  3. Planned

    Tier 2: Understanding

    An on-device model finds page structure, and a checker rejects any change that causes harm.

  4. Research

    Tier 3: Behavior

    When you seem stuck, WebAble offers help in one line. It never changes the page without asking.

Try WebAble in Chrome

WebAble is a senior project in active development and is not on the Chrome Web Store yet. You can build it from source in a few minutes.

View the code on GitHub
  1. Install Node.js 22 or newer and pnpm 10, then run: 
    pnpm install
pnpm extension:enable
  2. In Chrome, open chrome://extensions and turn on Developer mode.
  3. Choose Load unpacked and select apps/extension/.output/chrome-mv3.
  4. Open any website and click the WebAble icon.
